## [v0.6.0] - 2026-04-26

### Highlights

- Persistent sessions with automatic history loading and saving
- Context engine for token-aware conversation management
- Event hook system for agent lifecycle events
- Cron scheduler for periodic job execution
- MCP remote skill support for external tool servers
- Migration from omnistorage to omnistorage-core/kvs

### Breaking

- Storage imports changed from `github.com/plexusone/omnistorage` to `github.com/plexusone/omnistorage-core/kvs` ([`ac1f5ab`](https://github.com/plexusone/omniagent/commit/ac1f5ab))
- Local `storage/` package removed in favor of `omnistorage-core/kvs` backends ([`74c36c5`](https://github.com/plexusone/omniagent/commit/74c36c5))
- Compiled skill tools now use `skill.Tool` interface from omniskill ([`3323e30`](https://github.com/plexusone/omniagent/commit/3323e30))

### Added

- `sessions/` package with persistent session storage and tool integrations ([`755ca11`](https://github.com/plexusone/omniagent/commit/755ca11))
- `context/` package with token-aware context management and sliding window support ([`763c61d`](https://github.com/plexusone/omniagent/commit/763c61d))
- `hooks/` package with event dispatcher, registry, and webhook support ([`b2ad5ab`](https://github.com/plexusone/omniagent/commit/b2ad5ab))
- `cron/` package with scheduler, persistent job store, and tool integrations ([`176e6f8`](https://github.com/plexusone/omniagent/commit/176e6f8))
- `platform/` package with standalone platform abstraction ([`4ab3b29`](https://github.com/plexusone/omniagent/commit/4ab3b29))
- `skills/remote/mcp/` package for MCP server integration ([`41ea36f`](https://github.com/plexusone/omniagent/commit/41ea36f))
- Twilio SMS channel support with webhook handling ([`0301051`](https://github.com/plexusone/omniagent/commit/0301051))
- `RegisterAgentOption` for external compiled skill injection ([`16f6fb3`](https://github.com/plexusone/omniagent/commit/16f6fb3))
- `ProcessWithSession` method for stateful conversation handling ([`f0d0efc`](https://github.com/plexusone/omniagent/commit/f0d0efc))

### Changed

- Compiled skills now use `skill.Tool` interface from omniskill package ([`3323e30`](https://github.com/plexusone/omniagent/commit/3323e30))
- Storage migrated from omnistorage to omnistorage-core/kvs ([`ac1f5ab`](https://github.com/plexusone/omniagent/commit/ac1f5ab))
- MCP skill updated to use omniskill client and types ([`0f372c2`](https://github.com/plexusone/omniagent/commit/0f372c2))
- Twilio webhook path changed to `/webhook/twilio/sms` ([`41e210a`](https://github.com/plexusone/omniagent/commit/41e210a))

### Fixed

- gofmt linting compliance ([`fccc23d`](https://github.com/plexusone/omniagent/commit/fccc23d))

### Dependencies

- `github.com/plexusone/omnistorage-core` v0.3.0 (replaced omnistorage)
- `github.com/plexusone/omniskill` v0.6.0 (new)
- `github.com/robfig/cron/v3` v3.0.1 (new, for scheduling)
- `github.com/moby/moby/client` v0.4.0 → v0.4.1

## [v0.5.0] - 2026-04-19

- Storage abstraction layer with SQLite and in-memory backends
- Functional options pattern for agent configuration

### Added

- Compiled skills interface (`CompiledSkill`) and registry for registering Go functions as tools ([`078fc4f`](https://github.com/plexusone/omniagent/commit/078fc4f))
- Storage interface with `SQLiteBackend` and `MemoryBackend` implementations ([`f2680b7`](https://github.com/plexusone/omniagent/commit/f2680b7))
- Functional options (`WithCompiledSkills`, `WithStorage`, `WithObservability`) for agent creation ([`1d1aedb`](https://github.com/plexusone/omniagent/commit/1d1aedb))
- PlexusOne unified navigation and theme for MkDocs documentation site ([`fb5c661`](https://github.com/plexusone/omniagent/commit/fb5c661))
- Testing & Debugging guide with WebSocket smoke test instructions

### Fixed

### Dependencies

- `github.com/plexusone/omnivoice` v0.5.1 → v0.7.2

## [v0.4.0] - 2026-03-01

### Highlights

- Module migration from agentplexus to plexusone organization
- Batteries-included omnivoice with provider registry pattern

### Changed

- Module path migrated from `github.com/agentplexus/omniagent` to `github.com/plexusone/omniagent`
- Voice processor refactored to use `omnivoice.GetSTTProvider()` and `omnivoice.GetTTSProvider()` registry pattern
- Removed direct `omnivoice-deepgram` import - now auto-registered via `providers/all`

### Dependencies

- Upgrade `github.com/plexusone/omnivoice` to v0.5.1 (batteries-included with registry)
- Upgrade `github.com/plexusone/omnichat` to v0.3.0
- Upgrade `github.com/plexusone/omnillm` to v0.13.0
- Upgrade `github.com/plexusone/omniobserve` to v0.7.0
- Upgrade `github.com/plexusone/omniserp` to v0.8.0
