## [v0.18.0] - 2026-08-16

### Highlights

- Full skill-secrets lifecycle: SKILL.md declaration, global/per-skill config bindings, per-skill-type injection (MCP, OpenAPI, compiled), required-secret gating, and log/output redaction
- Team-mode agent secrets now fall back through the config bindings (per-agent > per-skill global > global), with a read-only admin view of the global bindings
- Email+password authentication for team mode (argon2id), alongside magic-link and Google/GitHub SSO
- Team-mode SPA redesign: persistent left nav matching claude.ai/ChatGPT/GitHub, plus translate and speech-to-text in the composer
- keeper:// vault scheme removed (no working provider ever existed); corrected fabricated Keeper documentation

## [v0.16.0] - 2026-08-10

### Highlights

- Team mode: multi-user deployments with PostgreSQL row-level security, allowlist-closed magic-link authentication, and private/group chats
- Virtual agents: named personas with per-agent skills, owner/maintainer roles, and a private/listed + featured discovery catalog
- Per-agent runtime binding of skills and agent-scoped secrets, isolated so two agents load disjoint secrets with no cross-leak
- Embedded web UI for team chats, agent configuration, catalog browsing, and superadmin curation
- Gateway hardening: authentication, origin validation, per-sender rate limiting, escalating auth backoff, and a Prometheus metrics endpoint
- Automatic session rollover, per-session tool/model overrides, and lifecycle event hooks

- Module migration from agentplexus to plexusone organization
- Batteries-included omnivoice with provider registry pattern

### Changed

- Module path migrated from `github.com/agentplexus/omniagent` to `github.com/plexusone/omniagent`
- Voice processor refactored to use `omnivoice.GetSTTProvider()` and `omnivoice.GetTTSProvider()` registry pattern
- Removed direct `omnivoice-deepgram` import - now auto-registered via `providers/all`

### Dependencies

- Upgrade `github.com/plexusone/omnivoice` to v0.5.1 (batteries-included with registry)
- Upgrade `github.com/plexusone/omnichat` to v0.3.0
- Upgrade `github.com/plexusone/omnillm` to v0.13.0
- Upgrade `github.com/plexusone/omniobserve` to v0.7.0
- Upgrade `github.com/plexusone/omniserp` to v0.8.0
